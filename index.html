Dues strands agents sdk

A background agent that reads your inbox for obligations rather than messages, and texts you only when one is genuinely urgent.

  • Python
  • Strands Agents SDK
  • Next.js
  • Neon Postgres
  • Gmail API
  • Telegram
  • Vercel
Source

The hard case is one sender with three kinds of mail. A company you applied to sends "pick an interview slot by tomorrow", "join our virtual career fair", and a monthly newsletter — same domain, completely different importance. No sender or keyword rule separates those, so Dues reads for what is being asked of you instead of who sent it.

Pipeline
An extractor that never sees the sender, domain or display name; a second, sender-aware verifier with access to thread history; and a deterministic router that takes the union of their urgent votes. No model decides whether to text you.
Output
Urgent goes straight to your phone over Telegram. Digest waits in an open-obligations list. Noise is logged and dropped. Duplicates attach to the existing obligation instead of texting again, and replying DONE a3f2 closes it.
Measured
A deterministic evaluator scores urgent recall, catastrophic-miss rate and same-sender separation. No LLM judge.

Nimbus agentic aws

Describe the infrastructure you want in plain English. Three agents plan it, deploy it, and keep it from running up a bill.

  • Python
  • FastAPI
  • Amazon Bedrock (Nova)
  • boto3
  • Next.js
  • TypeScript
  • Clerk
  • Supabase
Source Visit site

"I need a REST API with a database" becomes an architecture plan with a cost estimate, which you approve before anything is provisioned.

Architect
Turns the request into an AWS plan with cost estimates, optionally restricted to free-tier eligible services only.
Executor
Provisions and tags EC2, S3, DynamoDB and Lambda through boto3 once you approve, then generates setup.sh, teardown.sh, docker-compose.yml and an infrastructure manifest.
Bodyguard
Runs in the background watching CloudWatch metrics and auto-stops idle EC2 instances, so a box you forgot about does not turn into a surprise bill.
Visible
A live activity panel streams each agent's reasoning, so you can see what it is doing and why before you commit to it.

Course Agent cf_ai_course_agent

An AI teaching assistant that answers from a real syllabus and escalates everything it cannot answer to the professor.

  • TypeScript
  • Hono
  • Cloudflare Workers AI
  • D1
  • KV
  • Workflows
  • Pages
  • React 19
Source Visit site

A professor uploads a syllabus and a Cloudflare Workflow parses out deadlines, grading weights, policies and office hours. Students then ask questions against that course, not against a general model.

Tools
Eight of them — syllabus policy lookup, deadlines, grading weights, office hours, knowledge-base search, course-materials search, a grade scenario calculator, and ticket creation.
Escalation
When the agent is not confident, it files a ticket instead of guessing. The professor resolves or denies it and can fold the answer back into the knowledge base for the next student who asks.
Guardrails
It cites sources, never answers assignments or exams directly, and obeys per-course rules the professor writes into its system prompt.
Runs on
Workers, Workers AI (Llama 3.3 70B with tool calling), D1, KV, Workflows and Pages.
